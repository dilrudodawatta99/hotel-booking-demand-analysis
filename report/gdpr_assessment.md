# GDPR Article 5: Data Protection Principles Assessment

## 1. Lawfulness, fairness and transparency

The Hotel Booking Demand dataset is used for academic analysis. Its source and Creative Commons Attribution 4.0 licence are acknowledged. The analysis does not attempt to identify individual guests or make decisions about real customers.

## 2. Purpose limitation

The dataset is processed for the defined academic purpose of investigating hotel booking patterns and reservation cancellations. The data is not repurposed for unrelated activities.

## 3. Data minimisation

Only variables relevant to booking patterns, data quality and cancellation analysis are used in the analytical stages. Personal identifiers are not required for the research question. Results are primarily presented as aggregated statistics.

## 4. Accuracy

Data-quality checks identify missing values, duplicate records, invalid negative ADR values and records without guests. Cleaning decisions are documented. The original raw dataset is retained unchanged, allowing the processing steps to be reviewed.

## 5. Storage limitation

The project retains the original dataset and processed files only for the period necessary to complete and demonstrate the coursework. Unnecessary copies should be removed after the academic retention period.

## 6. Integrity and confidentiality

The dataset is stored within the coursework project and is not published with additional personal identifiers. The raw source is kept separate from processed outputs. Access to project files should be restricted to authorised users.

## 7. Accountability

The project documents its dataset source, licence, extraction information, SHA-256 checksum, data-quality findings, cleaning decisions and analytical methods. This provides evidence of responsible data handling.

## Limitations

The dataset is publicly available and does not provide sufficient information to establish the original legal basis for every aspect of its collection and processing. Therefore, this assessment explains how the coursework handles the data responsibly; it does not claim that the original collection or publication is fully GDPR-compliant.
